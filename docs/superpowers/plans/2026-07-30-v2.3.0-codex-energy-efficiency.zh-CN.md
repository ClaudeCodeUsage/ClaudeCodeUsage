# V2.3.0 Codex Beta R6 能耗与并发安全实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Codex warm refresh 在数据无变化时不重算、不写盘，并通过跨进程 lease 与唯一临时文件消除多窗口写入竞争。

**Architecture:** worker 在完整 refresh 周期前获取 index-path lease；`updateCodexIndex` 用 manifest、coverage、timezone 和 civil day 判断真实 no-op；worker 只保存有变化或 recovery 的结果。原子写入使用每次调用唯一的临时文件。

**Tech Stack:** TypeScript、Node.js worker_threads、`node:fs/promises`、`node:test`、VS Code Extension API

## Global Constraints

- 基线是 Codex Beta R5 commit `11aca0d7eecee7e79f2949fb7a0f1890412c7510`。
- 继承 V2.2.2 前台窗口 recurring-resource 节流。
- 不增加第三方运行时依赖。
- lock/index/diagnostics 不得包含 raw path、session ID、parent ID、prompt、response 或 command body。
- JSONL 保持只读。
- 日期、时区、迁移、恢复和文件变化必须绕过 no-op。

```ts
export type WindowActivityTransition = 'none' | 'resume' | 'suspend';

export class WindowActivityGate {
  constructor(private active: boolean) {}

  get focused(): boolean {
    return this.active;
  }

  update(nextFocused: boolean): WindowActivityTransition {
    if (nextFocused === this.active) return 'none';
    this.active = nextFocused;
    return nextFocused ? 'resume' : 'suspend';
  }
}

export function quotaFailureBackoffMs(failStreak: number): number {
  if (!Number.isFinite(failStreak) || failStreak <= 0) return 0;
  const exponent = Math.max(0, Math.floor(failStreak) - 1);
  return Math.min(3_600_000, 60_000 * Math.pow(2, exponent));
}
```
