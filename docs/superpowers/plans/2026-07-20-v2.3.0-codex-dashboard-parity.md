# v2.3.0 Codex 仪表板对齐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 把 Codex Beta 改造成与现有 Claude 仪表板同一视觉和交互体系的八标签用量面板，并增加真实、只读的 Codex 行为诊断。

**架构：** 在 `codexUsage.ts` 中只增加数字化范围、按月聚合和行为指标；`codexView.ts` 负责复用现有 Claude HTML/CSS 类渲染时间范围、柱状图、Token 构成条和表格；`webview.ts` 注入现有 Settings 面板、数字格式器和标签脚本。保持现有 Codex 索引 schema，不读取正文。

**技术栈：** TypeScript 5.8、VS Code Webview、Node `node:test`、现有增量 JSONL 索引、现有 i18n 与 SettingsStore。

## 全局约束

- 内部发布版本保持 `2.3.0`；source `package.json` 版本保持 `2.1.1`。
- 不显示或估算 Codex 美元成本。
- 不读取或渲染 prompt、response、command、tool argument、原始路径、session ID、credential 或私有数据库。
- 不新增 Codex Content、Branches 或 Workflows 页面。
- 所有可视化必须复用 Claude 的 `.tabs`、`.tab`、`.summary-grid`、`.summary-item`、`.chart-tabs`、`.chart-content`、`.chart-bars`、`.cost-composition`、`.model-item` 和 `.daily-table` 视觉语言。
- Reasoning 是 output 子集，任何构成或总量都不得重复相加。
- 八种 UI locale 同时补齐；若更新 README，七份 README 必须同步。
- Codex 主导 commit 使用 `Co-authored-by: OpenAI Codex <215057067+openai-codex[bot]@users.noreply.github.com>`，并附 Codex 生成页脚。
- 未经明确授权不 push、不创建 PR、不 merge、不发布。
