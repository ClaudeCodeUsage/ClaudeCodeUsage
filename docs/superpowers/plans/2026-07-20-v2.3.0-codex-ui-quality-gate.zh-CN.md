# v2.3.0 Codex Webview 质量门禁与 R4 交付实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用真实生产 Webview HTML、CSS 和 client script 建立 Codex 交互、状态恢复、无障碍、响应式、视觉和 VSIX 回归门禁，并生成可直接安装的 v2.3.0 Codex Beta R4。

**Architecture:** 纯 TypeScript 继续由 `node:test` 覆盖；浏览器层使用固定版本 Chromium。测试服务器通过最小 CommonJS `vscode` host stub 实例化编译后的真实 `UsageWebviewProvider`，调用生产 `getAlternateProviderContent()`，再由 Playwright `webServer` 和 `page.goto()` 加载。`acquireVsCodeApi` stub 把状态保存到同源 `localStorage`，因此 `page.reload()` 会真正重新请求、重新解析并重新执行生产 document，同时仍能模拟 VS Code 的 `getState()`／`setState()` 恢复语义。

**Tech Stack:** Node.js 20、TypeScript 5.8、`node:test`、`@playwright/test@1.61.1`、`@axe-core/playwright@4.12.1`、Chromium、GitHub Actions、`@vscode/vsce@3.9.1`。

## Global Constraints

- `@playwright/test` 固定为 `1.61.1`，`@axe-core/playwright` 固定为 `4.12.1`；二者只能是 devDependency。
- 不新增 runtime dependency；Playwright、Axe、浏览器、测试服务器和测试 fixture 均不得进入 VSIX。
- Harness 必须执行生产 renderer、生产 CSS、生产 Settings HTML 和生产 client script；不得复制一份测试专用产品页面或注入替代 Codex handler。
- 浏览器入口必须是 `tests/ui/support/server.mjs` + Playwright `webServer` + `page.goto()`；不得使用 `page.setContent()`，以确保 `page.reload()` 是完整 document reload。
- Fixture 固定 `now = 2026-07-20T12:00:00.000Z`、`timezone = Asia/Hong_Kong`、locale、viewport、theme variables 和动画状态；不得读取维护者的真实 Codex 日志。
- Axe serious／critical 必须为零；tab、segmented control、sort、disclosure 和图表下钻必须另有显式键盘断言。
- 八个 UI locale 在 360×800 与 1280×900 下不得产生 document/body 横向溢出；表格和图表只能在自己的 `.codex-scroll-region` 内滚动。
- 六张 canonical screenshot 必须在 `mcr.microsoft.com/playwright:v1.61.1-noble` 中生成并在相同容器中复验；不得直接用 macOS 像素结果作为 Linux CI 基线。
- `package-lock.json` 的根 `version`、`devDependencies` 必须与 `package.json` 完全一致；当前 `2.0.2` 根版本和幽灵 `@types/glob` 必须被 npm 正规修复。
- `.vscodeignore` 必须排除 `tests/**`、Playwright config、报告和结果；`.gitignore` 只排除生成结果，不排除测试源和六张基线。
- GitHub Actions 固定为 `test`、`ui`、`package` 三个 job；`package` 必须等待前两项通过。
- CI 和 publish 中的 VSCE 都固定为 `@vscode/vsce@3.9.1`。不得使用未固定的 latest；v2.3.0 不同步升级 release Node runtime。
- 不加入报告上传 action；测试失败由日志、本地同容器复现和 Playwright 本地报告诊断，计划中不得保留未解析的 action SHA。
- 不推送、不创建 PR、不合并、不发布 Release；本计划只形成经过验证的本地 R4 包。
- 每个行为先写测试并观察预期 RED，再做最小生产修复至 GREEN；基础设施 smoke 可先证明 harness 真实加载现有生产页面。

function sumTotals(files: CodexFileAggregate[]): ProviderTokenCounts {
  return files.reduce<ProviderTokenCounts>(
    (sum, file) => ({
      inputTotal: sum.inputTotal + file.total.inputTotal,
      cachedInput: (sum.cachedInput ?? 0) + (file.total.cachedInput ?? 0),
      outputTotal: sum.outputTotal + file.total.outputTotal,
      reasoningOutput: (sum.reasoningOutput ?? 0) + (file.total.reasoningOutput ?? 0),
      sourceTotal: (sum.sourceTotal ?? 0) + (file.total.sourceTotal ?? 0),

  );

import { createRequire } from 'node:module';

const require = createRequire(import.meta.url);
const { renderHarness } = require('./render-harness.cjs');
const locales = new Set(['en', 'de-DE', 'zh-TW', 'zh-CN', 'ja', 'ko', 'pt-BR', 'id']);

const server = createServer((request, response) => {
  try {
    const url = new URL(request.url ?? '/', 'http://127.0.0.1:4173');
    if (url.pathname === '/health') {
      response.writeHead(200, { 'content-type': 'text/plain; charset=utf-8' });
      response.end('ok');
      return;
    }
    if (url.pathname !== '/') {
      response.writeHead(404, { 'content-type': 'text/plain; charset=utf-8' });
      response.end('not found');
      return;
    }

    const requestedLocale = url.searchParams.get('locale') ?? 'en';
    const locale = locales.has(requestedLocale) ? requestedLocale : 'en';
    const theme = url.searchParams.get('theme') === 'dark' ? 'dark' : 'light';
    const html = renderHarness({ locale, theme });
    response.writeHead(200, {
      'content-type': 'text/html; charset=utf-8',
      'cache-control': 'no-store',
    });
    response.end(html);
  } catch (error) {
    response.writeHead(500, { 'content-type': 'text/plain; charset=utf-8' });
    response.end(error instanceof Error ? error.stack : String(error));
  }
});

`.github/scripts/vsixPolicy.mjs`：

```js
const FORBIDDEN_ENTRY_PATTERNS = [
  /^extension\/src\//,
  /^extension\/out\/test\//,
  /^extension\/tests\//,
  /^extension\/docs\//,
  /^extension\/\.github\//,
  /^extension\/\.(?:codex|claude|agents)\//,
  /^extension\/AGENTS(?:\.zh-CN)?\.md$/,
  /node_modules\/(?:@playwright|playwright|playwright-core|@axe-core|axe-core)\//,
  /(?:^|\/)\.env(?:\.|$)/,
  /\.(?:pem|key|p12|pfx)$/,
];

const REQUIRED_BUNDLE_MARKERS = [
  'data-codex-page="overview"',
  'data-codex-page="explore"',
  'data-codex-page="recommendations"',
  'data-codex-action',
  'ccu.codex.ui.v1',
];

const RETIRED_BUNDLE_MARKERS = [
  'data-codex-tab-button="recent"',
  'data-codex-tab-button="7d"',
  'data-codex-tab-button="30d"',
  'data-codex-tab-button="all"',
  'data-codex-tab-button="threads"',
  'data-codex-tab-button="projects"',
  'data-codex-tab-button="behavior"',
  'data-codex-tab-button="settings"',
];

export function assertSafeVsixEntries(entries) {
  for (const entry of entries) {
    if (FORBIDDEN_ENTRY_PATTERNS.some((pattern) => pattern.test(entry))) {
      throw new Error(`forbidden VSIX entry: ${entry}`);
    }
  }
}

export function assertCodexBundleMarkers(bundle) {
  for (const marker of REQUIRED_BUNDLE_MARKERS) {
    if (!bundle.includes(marker)) {
      throw new Error(`missing bundle marker: ${marker}`);
    }
  }
  for (const marker of RETIRED_BUNDLE_MARKERS) {
    if (bundle.includes(marker)) {
      throw new Error(`retired bundle marker: ${marker}`);
    }
  }
}
```

- [ ] **Step 3: 实现真实 VSIX verifier**

`.github/scripts/verify-vsix.mjs`：

```js
import { createHash } from 'node:crypto';
import { execFileSync } from 'node:child_process';
import { readFileSync } from 'node:fs';
import { resolve } from 'node:path';
import {
  assertSafeVsixEntries,
  assertCodexBundleMarkers,
} from './vsixPolicy.mjs';

const [, , requestedPath, requestedVersion] = process.argv;
if (!requestedPath) {
  throw new Error('usage: node .github/scripts/verify-vsix.mjs <file.vsix> [expected-version]');
}

const vsixPath = resolve(requestedPath);
const sourceManifest = JSON.parse(readFileSync(resolve('package.json'), 'utf8'));
const expectedVersion = requestedVersion ?? sourceManifest.version;
const entries = execFileSync('unzip', ['-Z1', vsixPath], { encoding: 'utf8' })
  .split(/\r?\n/)
  .map((entry) => entry.trim())
  .filter(Boolean);

assertSafeVsixEntries(entries);

const packagedManifest = JSON.parse(
  execFileSync('unzip', ['-p', vsixPath, 'extension/package.json'], { encoding: 'utf8' }),
);
if (packagedManifest.version !== expectedVersion) {
  throw new Error(
    `VSIX version mismatch: expected ${expectedVersion}, got ${packagedManifest.version}`,
  );
}

const javascriptEntries = entries.filter(
  (entry) => /^extension\/out\/.*\.js$/.test(entry) && !entry.startsWith('extension/out/test/'),
);
const bundle = javascriptEntries
  .map((entry) => execFileSync('unzip', ['-p', vsixPath, entry], { encoding: 'utf8' }))
  .join('\n');
assertCodexBundleMarkers(bundle);

const bytes = readFileSync(vsixPath);
const sha256 = createHash('sha256').update(bytes).digest('hex');
process.stdout.write(`${JSON.stringify({
  path: vsixPath,
  version: packagedManifest.version,
  files: entries.length,
  bytes: bytes.length,
  sha256,
}, null, 2)}\n`);
```
