# v2.3.0 Codex 仪表板完成计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将现有 Codex R2 从静态聚合页补齐为可本地试用的 v2.3.0 Beta，首先保证 Session 与项目名称真实准确，再完成统一外壳、筛选下钻、完整额度和 provider-aware 设置。

**架构：** 新增只处理身份元数据的 `codexIdentity.ts`；rollout 索引只持久化安全项目标签和子代理 nickname，`session_index.jsonl` 的线程标题在 provider 刷新时流式读取并仅保留于内存。`codexUsage.ts` 形成带 lineage、真实名称和项目下钻的 view model，`codexView.ts` 继续复用 Claude 的组件语言，`webview.ts` 只处理共享外壳和交互。

**技术栈：** TypeScript 5.8、Node `node:test`、VS Code Webview、现有增量 JSONL worker；不新增 runtime dependency。

## 全局约束

- 不读取 prompt、response、command 或 tool argument 正文。
- 不显示或持久化完整路径、原始 session ID、仓库 URL、credential 或私有数据库内容。
- 不估算 Codex 美元成本，不制造 Branches／Workflows。
- Session 标题来自 `session_index.jsonl`；项目名来自 rollout `session_meta` 的 Git URL 或 `cwd` basename。
- 无真实名称时明确降级，不使用顺序编号冒充名称。
- 旧索引身份补全必须有界，不得重读全部 token 历史。
- Reasoning 是 output 子集，不重复计数。
- 八个 UI locale 同步；若更新 README，七份 README 同步。
- 每个生产行为先写失败测试并确认 RED，再写最小实现并确认 GREEN。
- Codex 主导 commit 使用 `Co-authored-by: OpenAI Codex <215057067+openai-codex[bot]@users.noreply.github.com>` 与 Codex 生成页脚。
